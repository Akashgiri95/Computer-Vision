# Object Detection — YOLO

| Notebook | Model | Description |
|----------|-------|-------------|
| `Yolo11/Yolov11.ipynb` | YOLOv11n / YOLOv11s | Inference with pre-trained weights on crowd and road-crossing images |

**Included test images:** `Gathering.jpg`, `roadcross.jpg`  
**Pre-trained weights:** `yolo11n.pt` (nano), `yolo11s.pt` (small)

**Key learning:** One-stage detection pipeline, confidence thresholding, NMS, speed vs accuracy trade-off (nano vs small).
