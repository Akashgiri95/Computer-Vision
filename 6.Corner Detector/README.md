# Corner Detection

| Notebook | Description |
|----------|-------------|
| `Harris,Fast Corner Detector.ipynb` | Harris corner score computation, FAST (Features from Accelerated Segment Test), corner response visualisation |

**Key learning:**
- **Harris** — structure tensor eigenvalue analysis; stable but slow
- **FAST** — pixel ring test for real-time detection; basis for ORB
- Non-maximum suppression to thin detected corners
